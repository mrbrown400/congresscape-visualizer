# Local Government Source Research for M7-M14

Research date: 2026-07-14  
Scope: source refinement for CON-31, CON-35, CON-36, CON-38, CON-41, CON-49, CON-50, CON-59, CON-60, CON-64, CON-65, CON-67, and CON-70.  
Method: official government pages, official agency data portals, and first-party API documentation only. Linear was read for issue context; the verified refinements were then applied to the 13 issues in scope.

## How to read this note

- **Verified fact** means the cited first-party source directly supports the statement or the endpoint returned first-party metadata on the research date.
- **Proposed acceptance criterion** is recommended implementation behavior; it is not a promise made by the source owner.
- “Not stated” means the cited official page did not publish a commitment. It must not be converted into an inferred SLA or license.

## Cross-source acceptance criteria

These are **proposed acceptance criteria** for every adapter in this note:

1. Save the canonical source URL, retrieval time, HTTP validators when present, response content type, response byte hash, and raw source metadata.
2. Keep publication/event dates separate from retrieval dates. Preserve the source-native identifier and terminology.
3. Snapshot source metadata needed to reproduce a result: dataset/service ID, layer ID, API query, source-reported update timestamp, schema, effective date or boundary vintage, and document revision/hash.
4. Treat missing, not-yet-published, withdrawn, revised, inaccessible, and parser-failed as distinct states.
5. Do not invent a cadence, rate limit, or reuse license when the source does not state one. Start with conditional requests and conservative throttling, then calibrate from observed responses.
6. Keep HTML/PDF parsing behind source-specific adapters and fixture every source shape actually relied on.

## Source gaps that remain real

- A verified, documented structured API for City Clerk CFMS/ePackets was not found; the official HTML/PDF interfaces are the source.
- A first-party City council layer (13) and County supervisorial layer (26) are verified. Their source metadata/effective dates and geometry hashes still must be snapshotted at import time.
- No affirmative reuse license was found on the City Clerk pages or most cited Controller/DataLA metadata; `hfus-a659` is the verified exception and states Public Domain. “Publicly accessible” is not the same as “licensed for any reuse.”
- Numeric rate limits are not stated by the cited government source pages. Conservative throttling and conditional requests are proposed behavior, not official limits.
